E6_AFXT1: Fundamentos y Maquetación en Diseño Web

El diseño web abarca la planificación, conceptualización y ejecución de interfaces digitales. Se fundamenta en estándares del W3C para garantizar la accesibilidad, compatibilidad entre navegadores (cross-browser) y una navegación estructurada adecuadamente mediante el lenguaje de marcado HTML5.

Para lograr una correcta presentación visual, se implementa CSS3 (Cascading Style Sheets). Este estándar permite separar de forma clara la estructura semántica del contenido respecto a sus propiedades estéticas, controlando aspectos como el diseño responsivo, las paletas cromáticas y la tipografía.

Finalmente, la experiencia de usuario (UX) y la interfaz de usuario (UI) determinan el nivel de usabilidad del sitio. Integrar principios de jerarquía visual y maquetación fluida asegura una interacción óptima y eficiente para los usuarios finales.
